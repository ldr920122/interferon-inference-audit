Methods / About

Sources. CytoSig candidate profiles and reconstructed final-training membership are traced in the CSV index. The resolved 1,307-column reconstruction matches all 43 official centroids; membership remains inferred because an official final-column list was not released. The legacy 1,306-column reconstruction is retained separately. Current eligibility: 2 of 66 screen-flagged candidates meet the donor-paired design criteria (GSE236156 and GSE237879), both recovered post hoc; this is not an exhaustive census or prospective holdout certification. Legacy manual flags do not certify human review. huCIRA’s non-GEO Parse reference is not certified by this accession lookup. See README and the current audit tables for scope.

Titles and years come from our GEO/ArrayExpress search (original search 2026-10-12; selected metadata corrections 2026-10-14) and are blank for accessions outside it. CytoSig used a placeholder accession GSE99999 for one RNA-seq study (SRP109118); it is kept as written.

Limits. Accession-level matching only; sample-level overlap and re-deposited data are not detected. Search recall against known IFN sources was 92.0-100%.
